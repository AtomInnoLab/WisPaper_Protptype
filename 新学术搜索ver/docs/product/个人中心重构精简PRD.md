### 1.2 项目背景（Why）

当前个人中心的信息分散在设置菜单、会员与额度、存储空间、订单记录和多个购买弹窗中，存在以下问题：

1. **订阅状态不易判断**：会员等级、订阅周期、到期时间、自动续费和支付渠道分散展示，用户难以快速确认“当前权益是否正常”。
2. **Credits 概念重复**：月度额度、周额度、余额、已使用量和加油包余额同时出现，增加理解成本。
3. **交易信息不完整**：订单缺少支付渠道和账单下载入口，用户需要通过客服确认扣款来源或索取交易凭证。
4. **存储信息结构不一致**：高速存储、归档存储和额外购买容量的表达方式不同，且历史进度条不能帮助用户完成管理动作。
5. **身份信息不适合协作场景**：设置菜单以邮箱作为辅助身份信息，无法直接复制系统唯一标识进行问题排查或跨系统关联。
6. **信息密度影响体验**：大量副标题、解释文本、重复卡片和真实货币价格干扰主要任务。

本次重构以“状态可确认、额度可理解、交易可追溯、操作可完成”为原则，统一个人中心的信息架构和交互规则。

### 1.3 产品目标（What）

上线后 4 周内，以旧版为基线，达成以下目标：

| 目标 | 指标口径 | 目标值 |
|---|---|---:|
| 提升订阅信息理解效率 | 从进入个人中心到正确回答会员等级、到期日、自动续费状态的中位时长 | 降低 ≥ 30% |
| 提升账单自助完成率 | 订单详情或账单下载成功用户数 / 有账单诉求用户数 | ≥ 80% |
| 降低相关客服咨询 | 会员额度、扣款来源、账单下载类工单量 | 降低 ≥ 25% |
| 提升支付失败恢复率 | 支付失败后 7 天内成功更新支付方式并恢复订阅的用户占比 | 提升 ≥ 15% |
| 提升加油包转化 | 周额度耗尽后 24 小时内完成加油包购买的付费用户占比 | 提升 ≥ 10% |
| 保证核心任务可达 | 查看会员状态、复制 Open ID、查看周额度、下载账单、管理自动续费 | 100% 可在 3 次点击内完成 |

> 指标上线前需补充旧版基线；若无历史数据，首周作为观测基线，不直接用于结论判断。

### 2.2 信息架构与通用原则

个人中心保留四个一级页面：

| 页面 | 核心内容 | 不重复展示的内容 |
|---|---|---|
| 个人资料 | 头像、姓名、Open ID、邮箱、机构、研究领域 | 会员价格、Credits、订单 |
| 会员与 Credits | 当前会员、订阅周期、自动续费、周额度、加油包 | 完整支付工具、历史订单 |
| 存储空间 | 高速存储、归档存储、额外高速存储续费 | Credits 余额、会员价格 |
| 订单与账单 | 支付方式、订单、账单、发票 | 会员权益详情、额度进度 |
| 安全设置 | 密码、登录设备、账户注销 | 通知偏好、界面语言 |

通用要求：

- 页面一级标题直接对应任务，不增加无决策价值的副标题或解释文本。
- 同一信息只保留一个权威展示位置；概览卡片只呈现摘要并跳转至详情。
- 不设置 Usage 入口或独立 Usage 页面；个人中心只展示当前可用额度、重置日期和必要的余额明细。
- 个人中心的状态卡片不展示商品真实货币价格；价格仅在 Pricing、购买确认页和历史订单中出现。
- 设置菜单会员卡片与个人中心当前套餐卡片均以低信息层级展示已领取 Voucher 数量和剩余 Credits，不抢占会员等级与会员 Credits 主信息。
- 支付、会员订阅、加油包和额外存储均使用实体货币结算，不使用 Credits 支付。
- 日期统一采用用户本地时区；中文格式为“YYYY 年 M 月 D 日”，英文格式为“MMM D, YYYY”。

## 3. 功能详述

### 3.1 设置菜单身份卡片

#### 前台交互

| 用户行为 | 系统行为 |
|---|---|
| 点击左侧栏用户头像 | 展开设置菜单，展示头像、用户名和 Open ID |
| 点击 Open ID 后的复制按钮 | 将完整 Open ID 写入剪贴板；按钮切换为成功勾选，1.8 秒后恢复 |
| 使用键盘聚焦复制按钮并按 Enter/Space | 执行与点击一致的复制动作，并通过辅助技术播报“Open ID 已复制” |

#### 后台逻辑

- Open ID 由账号服务生成并保证全局唯一，前端只读展示，不允许用户修改。
- 用户信息接口返回 `open_id`；前端不得用邮箱、本地缓存 ID 或显示名替代。
- 复制行为仅发生在本地剪贴板，不记录 Open ID 明文；可记录匿名事件 `open_id_copy_success`。

#### 异常与边界状态

- Open ID 缺失：展示“暂不可用”，隐藏复制按钮，并上报账号数据异常。
- 剪贴板权限被拒绝：保留原文本，提示“复制失败，请手动复制”。
- Open ID 超长：单行省略展示，悬停或聚焦时显示完整值，复制始终使用完整值。

#### UI 文案

| 位置 | 中文 | English |
|---|---|---|
| 复制按钮 Tooltip | 复制 Open ID | Copy Open ID |
| 复制成功状态 | Open ID 已复制 | Open ID copied |
| 复制失败提示 | 复制失败，请手动复制 | Couldn't copy. Please copy manually. |
| 缺失状态 | 暂不可用 | Unavailable |

### 3.2 个人中心导航与概览

#### 前台交互

| 用户行为 | 系统行为 |
|---|---|
| 点击“个人设置” | 默认进入“个人资料”，左侧展示一级页面导航 |
| 点击不同一级页面 | 保留当前设置弹窗尺寸，仅替换右侧内容；当前菜单高亮 |
| 点击概览中的会员摘要 | 进入“会员与 Credits”页 |

#### 后台逻辑

- 首次打开并行请求账户、订阅、额度和风险状态；各模块独立加载，避免单接口失败阻塞整个页面。
- 最近访问的一级页面只在当前设备保存，不同步至账号。
- 页面 URL 或路由需保留设置页标识，便于从通知、支付结果页直接定位目标模块。

#### 异常与边界状态

- 单模块加载失败：该模块显示局部重试，不关闭设置页。
- 账号被限制：仍允许查看账单和安全信息，限制购买类操作。
- 小屏幕：一级导航折叠为顶部选择器，内容保持单列。

### 3.3 会员、订阅周期与自动续费

#### 前台交互

| 用户行为 | 系统行为 |
|---|---|
| 进入“会员与 Credits” | 套餐卡片展示会员等级、月付/年付、生效状态和关键日期 |
| 点击“升级” | 跳转 Pricing；当前会员和推荐升级项作为默认上下文 |
| 点击“关闭自动续费” | 二次确认停止续费的生效时间与权益终止日期 |
| 确认关闭自动续费 | 状态改为“将在到期后停止”，关键日期由“下次续费”切换为“到期” |
| 点击“重新开启” | 使用原支付方式恢复续费；成功后显示下一续费日期 |

#### 后台逻辑

- 会员状态以订阅服务返回值为准：`active`、`cancel_at_period_end`、`past_due`、`expired`。
- 月付与年付只影响扣款周期；会员 Credits 始终按月生成额度周期。
- 自动续费关闭采用期末取消，不立即回收会员权益。
- 会员卡片不展示真实货币价格；价格只在 Pricing、确认购买和订单记录展示。
- 个人中心的所有“升级”、“购买充值包”和“升级容量”操作统一打开 Pricing 弹窗。
- Pricing 中三张会员商品卡之后依次展示会员信息、连续订阅状态、当前支付方式和取消订阅入口；充值包商品紧随其后。
- 有效订阅期间支付方式只读，用户需先取消订阅才可更换。
- 所有订阅状态变更写入审计日志，包含用户、时间、变更前后状态和渠道。

#### 异常与边界状态

- Free 用户：显示 Free 和“升级”，不显示自动续费控件。
- 支付失败：显示“续费失败”，优先引导更新支付方式，不允许重复创建订阅。
- 已关闭续费后再次操作：接口需幂等，返回当前有效状态。
- 订阅刚发生变更：展示短暂处理中状态，轮询订单结果，最长 60 秒。

| 位置 | 中文 | English |
|---|---|---|
| 卡片状态 | 生效中 | Active |
| 卡片日期 | M 月 D 日到期 | Expires MMM D |
| 自动续费状态 | 自动续费已开启 | Auto-renewal on |
| 取消后状态 | 将在到期后停止 | Ends at expiration |
| 风险状态 | 续费失败 | Renewal failed |
| 主操作 | 升级 | Upgrade |
| 次操作 | 关闭自动续费 | Turn off auto-renewal |
| 恢复操作 | 重新开启 | Turn on auto-renewal |

### 3.4 Credits 周额度

#### 前台交互

| 用户行为 | 系统行为 |
|---|---|
| 查看当前套餐卡片 | 展示本周剩余 Credits、已使用量、周额度和重置日期 |
| 当前周额度发生消耗 | 数值和进度在任务结算后更新，不预估未结算消耗 |
| 本周额度耗尽 | 显示耗尽状态；存在加油包时继续消耗加油包，否则展示购买或升级入口 |

#### 后台逻辑

- 付费会员的月度 Credits 在每个额度周期开始时一次性生成，再拆分为 4 个连续 7 天的周额度。
- Plus / Pro / Max x2 / Max x5 的月度额度分别为 10,000 / 200,000 / 400,000 / 1,000,000；每周额度分别为 2,500 / 50,000 / 100,000 / 250,000。
- 周额度未使用部分不结转；新周开始时重置。第四周结束后开启新额度周期，上一周期未使用额度清零。
- 年付用户仍按月创建额度周期，不一次性发放全年 Credits。
- 消耗顺序：当前周会员额度 → 最早到期的加油包额度。
- 前端只展示服务端计算后的 `used`、`remaining`、`reset_at`，不得自行推算余额。

#### 异常与边界状态

- 额度服务延迟：展示上次更新时间和刷新入口，禁止显示负数。
- 跨周任务：以每笔消耗实际结算时间归属对应周。
- 会员变更：升级即时按新等级补齐当周可用额度；降级在当前订阅期结束后生效。
- Free 用户：沿用 Free 独立额度规则，不显示“第 N/4 周”。

| 位置 | 中文 | English |
|---|---|---|
| 额度标题 | 会员 Credits | Member Credits |
| 余额 | {count} 剩余 | {count} left |
| 重置日期 | 将在 M 月 D 日重置 | Resets MMM D |
| 周期位置 | 第 {n} / 4 周 | Week {n} of 4 |
| 耗尽状态 | 本周额度已用完 | Weekly credits used up |
| 更新时间 | 更新于 {time} | Updated {time} |

### 3.5 加油包

#### 前台交互

| 用户行为 | 系统行为 |
|---|---|
| 付费用户查看加油包模块 | 展示与当前会员等级匹配的唯一加油包、Credits 数量和 3 个月有效期 |
| 点击“购买加油包” | 打开购买确认页，展示本地币种价格和支付方式 |
| 展开加油包 Credits 池 | 展示每笔购买的购买日期、原始额度、剩余额度和到期日期 |
| Free 用户查看该区域 | 不展示加油包商品，展示升级入口 |

#### 后台逻辑

- 每个付费等级仅配置一个加油包；Credits 数量等于该等级月度 Credits，标准价格等于该等级月付价格。
- 年付用户购买时仍使用对应等级标准月付价格，不应用年付折扣。
- 每笔加油包到账后有效 3 个月，独立记录余额和到期时间；允许重复购买。
- 多笔加油包按到期时间从早到晚消耗；同一到期时间按购买时间先后消耗。
- Free 用户不能新购；降级后历史加油包仍可使用至到期。
- 个人中心摘要不展示真实货币价格；购买确认页按地区显示实体货币价格。

#### 异常与边界状态

- 重复支付回调：按支付订单号幂等发放，不能重复增加 Credits。
- 支付处理中：保持订单处理中，不提前发放额度。
- 购买后立即降级：已到账额度不回收，仍按原到期日处理。
- 加油包全部耗尽或过期：池总余额为 0，历史记录保留但默认折叠。

### 3.6 存储空间

#### 前台交互

| 用户行为 | 系统行为 |
|---|---|
| 进入“存储空间” | 以表格展示存储类型、已用/总容量、免费容量、已购容量、到期时间和操作，不显示进度条 |
| 点击“升级容量” | 打开 Pricing，并定位到当前套餐卡的高速存储选择器 |
| 选择存储档位 | 卡片内的月付或年付价格实时更新，且使用当前语言对应币种 |
| 点击“停止续费” | 二次确认；停止后容量保留至到期日，并显示到期后的数据处理方式 |
| 点击归档存储“查看文件” | 进入归档文件列表和恢复流程 |

#### 后台逻辑

- 高速存储总容量 = 会员基础容量 + 所有生效中的额外高速存储容量。
- 额外高速存储随会员统一结算；中文价格为每 10GB ¥6/月，英文价格为每 10GB $1/月，不使用 Credits 结算。
- Plus 不允许选择额外存储。Pro 选项为 50/75/100GB；Max x2 选项为 100/150/200/250GB；Max x5 选项为 250/500/750GB/1TB。
- 低等级最高档等于高一等级基础档：Pro 100GB = Max x2 100GB；Max x2 250GB = Max x5 250GB。
- 年付时所选额外存储与会员价格统一享受 15% 折扣；显示金额含小数时向上取整。
- 停止续费采用期末取消；到期后超出可用高速容量的数据按存储 PRD 进入归档流程，不立即删除。
- 归档存储容量为实际归档文件占用量，不计入可直接使用的高速存储额度。
- 存储数值以字节存储，界面统一按 GB/TB 格式化并标明舍入规则。

#### 异常与边界状态

- 购买后总容量小于当前使用量：禁止选择无效容量，提示至少需要的容量。
- 停止续费后再次操作：展示“已停止续费”和到期日，接口保持幂等。
- 支付失败：不增加容量，订单进入失败状态并提供重试。
- 到期时存在运行中任务：不中断任务；任务完成后执行归档判定。

### 3.7 支付方式

#### 前台交互

| 用户行为 | 系统行为 |
|---|---|
| 查看支付方式 | 展示渠道、支付工具摘要、状态及适用订阅，不展示完整账号或卡号 |
| 点击“添加支付方式” | 打开支付渠道选择和安全绑定流程 |
| 点击“设为默认” | 更新后续订阅扣款工具，不影响已完成订单 |
| 订阅期间尝试更改或解绑 | 支付方式保持只读，引导用户先取消订阅 |

#### 后台逻辑

- 支持支付宝、Airwallex、Stripe；实际可用渠道由用户地区、币种和商品类型决定。
- 服务端仅保存支付平台 Token、渠道、品牌、末四位和有效期，不保存完整卡号或支付密码。
- 会员与其所选存储规格作为同一订阅统一使用当前支付方式；订单需记录实际支付渠道与支付账户脱敏快照。
- 更新支付方式后，对 `past_due` 订阅触发一次受控重试，避免重复扣款。

#### 异常与边界状态

- 支付工具过期：标记“需要更新”，阻止设为默认。
- 渠道暂不可用：保留原绑定信息，隐藏新交易入口并提示稍后重试。
- 用户解绑唯一支付方式：无自动续费订阅时允许；有订阅时必须先关闭续费或添加替代方式。

| 按类型或时间筛选 | 更新列表和结果数，筛选状态保留在当前会话 |
| 点击“下载账单” | 下载对应订单的付款账单/收据，不跳转发票申请 |
| 点击“申请发票” | 进入发票信息填写；仅允许选择可开票的已支付订单 |

#### 后台逻辑

- 订单类型包括会员订阅、加油包、额外存储和退款。
- 订单保存实际支付币种、金额、渠道、订阅周期及支付平台交易号快照。

- 退款订单与原订单关联，金额使用负数或明确退款标识，不覆盖原订单。

- 账单生成失败：允许重新生成并记录失败原因。
- 支付失败订单：金额仍展示尝试支付金额，但无账单下载入口。
- 退款中：原账单保留；退款完成后增加退款凭证。
- 空列表：根据是否存在筛选条件展示不同空状态。
